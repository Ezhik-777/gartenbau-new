**Created:** 2026-02-15
**Status:** Planning
**Target Completion:** 3-4 weeks
**Estimated Hours:** 60-80 hours

## 🎯 Overview

Полный редизайн Gartenbau Z.M. с современным clean дизайном, parallax эффектами, зеленой природной темой и улучшенной галереей. Миграция с базовой Astro архитектуры на премиум-уровень с профессиональными визуальными эффектами и улучшенной производительностью.

### Ключевые цели:

1. **Визуальный редизайн** - Clean, современный, профессиональный
2. **Parallax эффекты** - AOS + CSS animations для плавной анимации
3. **Природная тема** - Зеленая палитра с анимированными листьями
4. **Улучшенная галерея** - Before/After слайдеры + отдельная страница
5. **Analytics & PWA** - Google Analytics 4 + улучшенный Service Worker
6. **Оптимизация изображений** - Sharp integration + responsive images

### Текущее состояние:

- ✅ Astro 4.3.0 с Islands Architecture
- ✅ 11 компонентов (5 static + 3 islands)
- ✅ View Transitions API
- ✅ WCAG AA compliance
- ✅ 3 Schema.org types
- ⚠️ Базовый дизайн (нужен апгрейд)
- ⚠️ Простая галерея (нужен функционал before/after)
- ❌ Нет parallax эффектов
- ❌ Нет GA4
- ❌ Нет image optimization pipeline

  ```javascript
  import sharp from 'sharp';
  import { glob } from 'glob';

  const images = await glob('public/img/image_*.webp');

  for (const img of images) {
    await sharp(img)
      .resize(1920, null, { withoutEnlargement: true })
      .webp({ quality: 85 })
      .toFile(`public/img/optimized/${basename(img)}`);

    // Generate responsive sizes
    await sharp(img).resize(640).webp({quality: 80}).toFile(`${name}-sm.webp`);
    await sharp(img).resize(1024).webp({quality: 85}).toFile(`${name}-md.webp`);
    await sharp(img).resize(1920).webp({quality: 85}).toFile(`${name}-lg.webp`);
  }
  ```
- [ ] Запустить оптимизацию всех 180 изображений
- [ ] **Создать** `src/utils/getImageSrcSet.ts`:
  ```typescript
  export function getImageSrcSet(imageName: string) {
    return {
      src: `/img/optimized/${imageName}-lg.webp`,
      srcset: `
        /img/optimized/${imageName}-sm.webp 640w,
        /img/optimized/${imageName}-md.webp 1024w,
        /img/optimized/${imageName}-lg.webp 1920w
      `,
      sizes: '(max-width: 640px) 640px, (max-width: 1024px) 1024px, 1920px'
    };
  }
  ```

## ⚠️ Risks & Mitigations

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|-----------|
| AOS library увеличивает bundle | Medium | Medium | Lazy load AOS, use only where needed |
| Parallax вызывает jank | Low | High | Use CSS transforms, test 60 FPS |
| Before/After slider тяжелый | Low | Medium | Code splitting, lazy load |
| Masonry layout breaks в Safari | Low | Medium | Multi-column fallback, test Safari |
| GA4 влияет на privacy compliance | Medium | High | Proper consent, update datenschutz |
| Image optimization слишком долгий | Low | Low | Cache optimized images, run once |
